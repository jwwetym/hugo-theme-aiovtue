今天咱们聊第四个心脏病案，也是这组案子里**最重的一个**。

患者男性，48岁，高血压冠心病多年，近年又确诊**心衰早期**。心脏造影显示**血管已经堵塞70%左右**，医院建议放支架，但患者坚持用中药治疗。

初诊时他的主要症状：胸闷气短明显，睡眠很差，**夜里两点到四点之间容易醒来**，饭后胃胀，大便费力，汗多，动则更甚。


#### 一、先看舌脉

**舌象**：舌形大致正常，但**舌尖有三角形的凹陷**，胃区有反光点并有部分隆起，舌根凹陷，苔薄白腻。

**脉象**：

| 部位 | 脉象 |
|------|------|
| 右手关脉 | 浮滑滞，沉取微劲滑滞 |
| 右肺脉 | 弹指 |
| 右脾脉 | 滑滞微弹指 |
| 右命门脉 | 微弹指 |
| 左手脉 | 浮细滞，沉取微劲滑滞 |
| 左心脉 | 弹指 |
| 左尺脉 | 劲滑滞 |

这个脉象里反复出现一个字——**劲**。

> 劲是什么？是血管紧张度高、压力大，**阳气被邪气逼迫不能舒展**的表现。

再加上多处**弹指**，说明邪气很盛。

整个格局是**阳虚阴盛、经络不通**，治法用**温阳通络、活血化瘀，按照次第进行**。


#### 二、治疗总览

这个案子的治疗分**两诊**，第一诊五步，第二诊又五步，加起来**十张方子**，足足治了**半年以上**。

我们一诊一诊看。


#### 三、第一诊：五步走

##### 第一步：平巽大法（守神）

**方子**：硃茯神、柏子仁、远志、石菖蒲、高良姜、肉桂、砂仁、炙甘草、葱白、全瓜蒌、薤白、丹参、党参、鹿角片。

和前一个案子比，这个方子少了两味药、换了丹参。

关键药物解析：

| 药物 | 作用 |
|------|------|
| 硃茯神 | 安定魂魄、心神安宁 |
| 石菖蒲 | 启心窍，心中之气刻刻交于四脏 |
| 砂仁 | 纳五脏之气达于水火交济之中 |
| 柏子仁 | 宁心益智，君火明照万方 |
| 高良姜 | 大温脾胃、化脾胃之滞 |
| 肉桂 | 温血暖气，气血交流、三焦通会 |
| 葱白 | 引通百脉，四旁之气归于中土 |
| 全瓜蒌 | 开三壳润肠道、宽胸膈 |
| 薤白 | 通经达络、引脉归要 |
| 丹参 | 通气血、血脉四通八达 |
| 党参+鹿角片 | 刚柔相济，精气交流、阴阳和合 |

> 这一步从**神**入手，把心神稳住、胸膈打开、气血通道疏通，为后续的温通做准备。


##### 第二步：桂枝法（开表建中）

**方子**：桂枝、生白术、生姜、炙甘草、小茴香、陈皮、法半夏、硃茯神、砂仁、全瓜蒌、薤白、三七、党参、鹿角片、紫石英。

| 药物 | 作用 |
|------|------|
| 桂枝 | 拔动太阳、透达少阴 |
| 生白术 | 强脾土助运化 |
| 小茴香 | 醒肝脾、土木无争 |
| 陈皮+法半夏 | 一开外二降逆，清浊得分 |
| 硃茯神 | 上通下达、奠安中宫 |
| 三七 | 活血化瘀（叶子非三即七，木火之性） |
| 紫石英 | 交济水火、坎离既济 |

> 这一步把**表打开、中焦建立起来**，三七开始活血化瘀。


##### 第三步：附子桂枝法（表里同温）

**方子**：制附片、生姜、桂枝、生白术、淫羊藿、炙甘草、陈皮、法半夏、硃茯神、砂仁、全瓜蒌、薤白、丹参、党参、鹿角片。

| 药物 | 作用 |
|------|------|
| 附子 | 拔动火炉、温暖水泉，水气沸腾升于天宫 |
| 姜桂草 | 连成一气，化尽群阴，真阳起伏连续不息 |
| 生白术+淫羊藿 | 导阴阳往来之机，上下相通源源不息 |

> 这一步**姜桂附齐上**，心阳肾阳同时温，**生命之轴开始重建**。

> ⚠️ 特别注意的是，如果血压高的时候加入**生铁落**，这是镇降逆气、稳住血压的用法。


##### 第四步：川乌附子法（透邪通络）

**方子**：制川乌、制附片、生黄芪、党参、三七、炙甘草、酸枣仁、柏子仁、全瓜蒌、薤白、丹参、**硫黄**、石菖蒲、独活、蒲公英。

| 药物 | 作用 |
|------|------|
| 川乌 | 冲开一条无人之路，奇经八脉十二正经的末端毛络皆可如潮汐而动 |
| 附子 | 温化之性再助一臂之力 |
| 三七 | 疏通脉络，气血循行有规 |
| 黄芪 | 迎水精达于四方，化精为气 |
| 酸枣仁+柏子仁 | 敛神安志，通达心脾 |
| **硫黄** | 仙丹之火、水石之精，温温暖暖养正阳之气 |
| 独活 | 开启浊路，鼓荡寒湿流行于外 |
| 蒲公英 | 借坎水沸腾之力，扫尽秽浊尘埃 |

> 这一步用**川乌冲开深层的经络瘀堵**，**硫黄温养下焦真阳**，真正开始处理血管堵塞70%的核心问题。


##### 第五步：四逆填精法（收功固本）

**方子**：制附片、制川乌、筠姜、炙甘草、肉桂、山萸肉、全瓜蒌、薤白、丹参、三七、党参、生黄芪、鹿角片、龟板、甘松。

| 药物 | 作用 |
|------|------|
| 附片 | 养生长收藏之气，交纳于元阴元阳之中 |
| 川乌 | 扫清升降道路中的障碍 |
| 鹿角片 | 通督脉贯肾水 |
| 龟板 | 通任脉滋心火 |
| 山萸肉 | 沟通心肾、交济坎离、收纳任督 |
| 甘松 | 通经脉，人活一口热气得以生生不息 |

> 这一步是彻底的**收功填精**，把下焦真阳、任督二脉、精髓全部补足。


#### 四、二诊：为什么还要继续治？

一诊五步走完，患者坚持服药到二诊，已经过了**大半年**。

2021年7月二诊时，患者自己感觉**效果良好**：

- 一切症状显著减轻
- 血压接近正常：**145/80**
- 西药减去了大部分
- 睡眠恢复正常

但仍然有**活动后胸闷气短、双下肢轻度水肿、脘腹胀满明显**，偶尔咳嗽无痰。

舌象：舌尖向左侧弯曲，舌尖凹陷呈三角形并右侧缺损，肺区有反光点，胃区有暗影。

脉象：右手寸脉浮，沉取细滞稍紧，肺脉微弹指，脾脉气滞，右尺弱滞。左手脉微浮，沉取细滞稍紧，心脉微洪，肝脉气滞湿滞，尺脉短滑滞。

二诊为什么还要继续治？

因为大的方向虽然对了，但还有一些**残余问题**：外感风寒的迹象、肺络不通、肝气郁滞、下焦仍然不够稳固。

所以二诊重新设计了五步次第，和前面五步的思路略有不同。


#### 五、第二诊：再走五步

**二诊第一步——桂枝法调肺气**

专门处理外感风寒和肺络不通的问题。加了**广紫菀**与**石菖蒲**疏理肺络，肺络通胃通膻中，膻中可开、君火可明。

**二诊第二步——桂枝法调肝气**

把肝气调顺，因为肝郁气滞也会影响心脉通畅。加了**吴茱萸**温木热土，**茵陈**化湿中蕴郁之热。

**二诊第三步——附子桂枝法（加强版）**

继续强化三立之法，同时加了**广木香**和**佛手**理气，**土茯苓**利湿消肿。

**二诊第四步——附子桂枝法加延胡索郁金**

在第三步基础上加了**延胡索**和**郁金**，专门解决瘀血导致的疼痛和气郁。

**二诊第五步——川乌附子法（加益母草）**

用川乌法继续疏通经络，加了**益母草**活血利水，呼应下肢水肿的问题。

**二诊第六步——四逆填精法（用生附子）**

**生附子**大热纯阳补先天之火种，佐川乌透达下行道路，筠姜温中焦土气而调和上下。**红参**益元阴而生气，与附子相合刚柔相济、阴阳和合。

> 生附子比制附子力量更猛，配合川乌、筠姜、红参、鹿龟二板，把下焦的火种和精髓彻底补足。


#### 六、随访结果

2022年1月随访，患者情况**非常好**：

- 血压恢复正常
- 冠心病**未再发作**
- 心衰**已经恢复正常**
- 胸闷气短**基本上没有出现过**

正在服药巩固或服用培元固本散维持。


#### 七、这个案子最核心的启示

按语里有一段话非常重要：

> 现代人的高血压、冠心病、心梗，根源在于**违背了天地自然规律**。古人日出而作日落而息、食饮有节起居有常，现代人完全做不到。所以治疗思路就是要**解决人与天地沟通的问题**。

扶阳医学的切脉辨证非常精准：

| 脉象 | 治法 |
|------|------|
| 脉有表证 | 桂枝法通天 |
| 脉有里证 | 附子法人地 |
| 表里皆阳虚 | 附子桂枝法 |
| 脉劲 | 川乌法 |
| 特殊情况 | 非附桂法 |

这个病人从**硃茯神法**（守神）→**桂枝法**（开表）→**附子桂枝法**（立火极、立土极、立水极）→**川乌法**（透达经络）→**四逆填精**（收功），因为病重，二诊又调整次第重新走了一遍，从调肺到调肝到温通表里到化瘀到填精，**步步为营**。

前后十张方子，半年多时间，把一个心脏堵塞70%、心衰早期的病人，拉回到血压正常、心梗未再发作、心衰恢复的状态。


#### 今日小结

> **第一，** 脉象里的“劲”和“弹指”是关键信号——说明阳气被邪气逼迫、血管紧张度高，需要用川乌法透达疏通；
>
> **第二，** 危重心血管病的治疗不是一张方子治到底，而是根据病势变化不断调整处方结构——守神→开表→建中→温通→通络→填精，步步为营；
>
> **第三，** 这个案子完整展示了扶阳医学治疗复杂慢性病的全部程序，每一步的换挡都有明确的脉证依据，这才是中医治大病的真正面目。
