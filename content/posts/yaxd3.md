今天咱们聊
### 第三个心脏病案。

和前两个案子比起来，这个案子的患者年轻一些，**40岁，女性**，但病情的复杂程度一点不低。


#### 一、先看整体情况

她的主诉很典型：经常**心悸、心慌、胸闷、气短**，活动之后加重，已经有半年多了。动态心电图报告提示**早搏合并心肌缺血**。

同时月经不正常：经期七天左右，有**痛经、血块、量多**。

其他伴随症状：睡眠不好，梦多，胃口差，汗多，手脚凉，怕冷。

**舌象**：舌胖润，心胃区有反光点，舌根平坦，苔薄白。

**脉象**：

| 部位 | 脉象 |
|------|------|
| 右手 | 浮稍滑，关脉明显，沉取紧滞滑 |
| 右肺脉 | 湿滞 |
| 右脾脉 | 滑滞弱 |
| 右尺 | 火弱 |
| 左手 | 略浮，沉取细紧滞 |
| 左心脉 | 气滞 |
| 左肝脉 | 细紧稍滑 |
| 左膀胱脉 | 细紧滞 |
| 左尺 | 弱短 |

这个脉象说明什么？**下焦阳气不足，中焦湿滞，心脉不通。**

整个格局是**阴盛阳衰**，所以医家定的治法叫：

> **扶阳抑阴、顺势调整月经。**


#### 二、为什么一定要“顺势”？

为什么提到顺势调整月经？

因为这位患者的冠心病发作和月经周期有**非常密切的关系**。

按语里说：**40岁之后的女性冠心病，治疗要遵循月经规律来顺势而为。**

什么叫顺势？

- **月经前期**：能量向上发越，就顺着这个趋势升发阳气；
- **月经期**：能量向下转换，就顺着这个趋势让瘀血排出；
- **月经后**：气血亏虚、经络不通，就透络益气，然后大补气血。

这个思路和前面两个案子完全不同——它不是固定时间服药，而是**跟着月经周期走**。

所以这个案子的五步方药，**每一步对应的是月经周期的不同阶段**。


#### 三、五步方药详解

##### 第一步：经前期之前——平巽大法（调神调气）

**方子**：硃茯神、琥珀、柏子仁、远志、石菖蒲、高良姜、肉桂、砂仁、炙甘草、葱白、瓜蒌壳、薤白、厚朴、党参、鹿角片。

这个方子很有意思——**它不直接治心脏，而是从神入手。**

医家说这叫**平巽大法**。巽在八卦里属风、属胆。胆是中正之官，决定十一脏的气机升发。胆气能降，肝气才有升发的可能。

关键药物解析：

| 药物 | 作用 |
|------|------|
| 硃茯神 | 镇灵台而行阴水，水去而云雾可拨 |
| 琥珀 | 安神智，交纳于坎离之中，上下交通 |
| 柏子仁 | 引魂魄于肝脾之内，交达心肾 |
| 远志+石菖蒲 | 开心窍、理膈膜、开贲门 |
| 高良姜 | 化脾胃之阴，助收纳消磨 |
| 肉桂 | 温化气血，让气血交流无阻 |
| 砂仁 | 纳五脏之气归于生生化化之中 |
| 葱白 | 引通心脉，心肾相照，迎水就火、引火就下 |
| 瓜蒌壳+薤白 | 开胸膈、疏胃结 |
| 厚朴 | 降逆气 |
| 党参 | 引肺中之气交于中，导脾中精气上润心肺 |
| 鹿角片 | 助阳添精，阴阳相合 |

> 这一步从**神和气**的无形层面切入，把心神稳住、胆气调顺、胸膈打开，为后续治疗铺路。


##### 第二步：月经期服用——顺势排瘀

**方子**：桂枝、制川乌、炮姜、炙甘草、当归、吴茱萸、延胡索、血竭、肉桂、怀牛膝、仙鹤草、蛇床子、杜仲。

这个方子的核心是**顺势向下转化能量**。月经期胞宫应该排瘀，就顺着这个趋势往下走。

关键药物解析：

| 药物 | 作用 |
|------|------|
| 桂枝 | 开太阳之气，让气机上行无阻 |
| 川乌 | 行冲任二脉的道路，让精华与能量顺势下行 |
| 炮姜+炙甘草 | 辛甘化阳、苦甘化阴，三焦气机自然 |
| 当归 | 润木镇风，引气血交于肠胃 |
| 吴茱萸 | 引肝木升发于上，上下通达 |
| 延胡索 | 破膈间滞气，行阴阳界中之留污 |
| 血竭 | 达于空窍，化窍中之瘀、行窍中之滞 |
| 怀牛膝 | 引血脉向下流行 |
| 仙鹤草 | 升提收纳上达，升降协调 |
| 杜仲+蛇床子 | 疏导筋络，迎辛温之品流达筋络薄膜之间 |

> 这个方子在月经期服用，目的就是**顺着经血下行的趋势，把胞宫里的瘀滞一并带走。**


##### 第三步：月经前期服用——顺势升发

**方子**：桂枝、生白术、淫羊藿、生姜、炙甘草、白芷、天麻、厚朴、瓜蒌壳、薤白、丹参、硃茯神、砂仁、党参、鹿角片。

月经前期能量向上发越，所以用**桂枝法借势升发阳气**。

关键药物解析：

| 药物 | 作用 |
|------|------|
| 桂枝 | 由太阳少阴升举于上，温益上下 |
| 生白术+淫羊藿 | 阴阳交合、水温土暖 |
| 生姜+炙甘草 | 心脾互照，两神明可通 |
| 白芷 | 通肺达脾，上下气机鼓荡而出 |
| 天麻 | 镇风透肌，助气血润泽肤表 |
| 丹参 | 入血脉消除瘀滞 |
| 党参+鹿角片 | 刚柔相济，气血交流 |

> 这个方子在月经前服用，**顺着阳气升发的趋势把心阳振作起来**，让中焦运化得力，这样月经来的时候才有足够的气血去完成排瘀。


##### 第四步：月经期后方——透络益气

**方子**：制川乌、生黄芪、党参、丹参、炙甘草、法半夏、郁金、硃茯神、瓜蒌壳、薤白、天花粉、瞿麦、石菖蒲、独活、蒲公英。

月经之后气血亏虚，经络容易不通。这个阶段用**川乌法透达脉络、益气活血**。

关键药物解析：

| 药物 | 作用 |
|------|------|
| 制川乌 | 破阴阳凝对之所，达阴阳末端交汇之地 |
| 党参+丹参 | 益气生血，让化源与运化长期运转 |
| 黄芪 | 迎水精达于四方，化精为气 |
| 法半夏 | 拨网油调顺逆，让脂膏流达筋络 |
| 郁金 | 解五脏之郁，解五行之制 |
| 天花粉 | “仙女散花、久旱遇甘霖” |
| 瞿麦 | 去霾之用，阴霾化为乌有 |
| 石菖蒲 | 开膻中传达神明，君火得明 |
| 独活 | 透出网膜，驱风寒湿于肌腠皮毛 |
| 蒲公英 | 禀中和之性，循循而升 |

> 这个方子在经后用，把经期排瘀后留下的经络不通彻底清理掉，**为最后的大补气血开路。**


##### 第五步：收功——大补气血填精

**方子**：党参、黄芪、阿胶、炮姜、肉桂、山萸肉、炙甘草、瓜蒌壳、薤白、丹参、甘松、鹿角片、银杏叶、红景天、广木香。

这个方子是**党参黄芪法**——最后的收功，把气血精髓彻底补足。

关键药物解析：

| 药物 | 作用 |
|------|------|
| 党参 | 益肺脾，滋肺源而行运转 |
| 黄芪 | 迎肾中之阳气透达巅顶 |
| 炮姜 | 引离火与土相合，阳明太阴两相旋转 |
| 山萸肉 | 益肾源润离阴，引气与血相合 |
| 肉桂 | 温血，气血交往不息 |
| 鹿角片 | 壮督脉添阳精 |
| 阿胶 | 育任脉滋润阴液 |
| 甘松 | 入土而疏木，木土共荣 |
| 广木香 | 通中宫而疏脉道，三焦一齐相贯 |
| 红景天 | 空虚之处皆含脉血之气 |
| 银杏叶 | 令四末气血畅行无阻 |

> 这个方子让**任督循环、公转畅行，坎离交合不断**，身体自己进入良性循环。


#### 四、随访结果

2021年3月回访，患者说：

- 胸闷气短几乎消失了
- 有力气了
- 心跳正常
- 复查心电图**基本恢复正常**

月经期仍有痛经，偶尔头痛头晕，但以前是天天有，现在已经好太多了。只是月经间隔三个月才来，因为中间服药不及时。还有些便秘，医家说先通大便，后续再调方。


#### 五、这个案子最大的启示

> **女性的心脏病，不能和月经周期脱钩。**

同样的冠心病，放在40岁女性身上，治疗必须跟着月经走：

| 阶段 | 策略 |
|------|------|
| 经前 | 升发阳气 |
| 经期 | 顺势排瘀 |
| 经后 | 透络益气 |
| 收功 | 大补填精 |

每一步都在**顺势而为**——借着身体本身的气血潮汐：

- 该升的时候帮他升
- 该降的时候帮他降
- 该排的时候帮他排
- 该补的时候帮他补

如果你逆着这个周期去治——比如经期该排瘀的时候你拼命补，或者经前该升发的时候你去清火——那就不是治病，是**跟身体对着干**。

这个案子把 **“顺势而为”** 这四个字，讲得明明白白。


#### 今日小结

> **第一，** 40岁以后女性冠心病，必须问月经、看周期，治疗要和月经节律同步；
>
> **第二，** 经前升阳、经期排瘀、经后通络、最后填精——每一步都是顺着身体的气血潮汐走；
>
> **第三，** 顺势而为不是被动等待，是借着身体的趋势帮它一把，该升则升、该降则降、该排则排、该补则补。

听懂这个案子，你对 **“顺势而为”** 四个字的理解，会再深一层。
